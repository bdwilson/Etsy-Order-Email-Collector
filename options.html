⚙️ Etsy Order Email Collector Options

Export Settings

When enabled, CSV exports will include the Order ID column alongside email addresses.

CSV Format Note

The exported CSV includes two columns:

  • Order ID - The Etsy receipt/order ID
  • Email - The customer's email address

This format is compatible with etsy-lettertrack for order tracking integration.

Push to etsy-lettertrack

Posts each Order ID + Email pair straight into a running etsy-lettertrack instance, so there is no CSV to import by hand. Because this extension reads Etsy's own data, the order number is exact and addresses are linked immediately rather than guessed.
Change this only if you run etsy-lettertrack on a different port or host. Saving a new host asks Chrome for permission to reach it — the extension cannot post to a host you have not approved.
Leave on to keep a local copy as well. A CSV is downloaded regardless if the push fails, so a collection run is never lost.

Data Handling

When enabled, collected orders will be cleared after successful export.
