⚙️ Etsy Order Email Collector Options

Export Settings

When enabled, CSV exports will include the Order ID column alongside email addresses.

CSV Format Note

The exported CSV includes two columns:

  • Order ID - The Etsy receipt/order ID
  • Email - The customer's email address

This format is compatible with etsy-lettertrack for order tracking integration.

Push to an API

Posts each Order ID + Email pair straight to a URL you control, so there is no CSV to import by hand. Works with etsy-lettertrack out of the box, and with anything else that accepts the request below.
Saving a host the extension hasn't used before asks Chrome for permission to reach it — it cannot post to a host you have not approved.
Turn this off to push only. Every run is kept either way, and the popup offers a Download CSV button afterwards, so switching this off never means losing a collection.

Push API format

Point the endpoint at any server that accepts this. It is a plain POST with Content-Type: application/json:

{
  "contacts": [
    { "email": "buyer@example.com", "order_id": "4147089582" },
    { "email": "someone@example.net", "order_id": "4147089583" }
  ]
}

Every order is sent in one request when collection finishes — not one request per order. Orders with no email address on the Etsy page are left out. order_id is Etsy's receipt ID, sent as a string.

Any 2xx response counts as success. The body is optional — reply with an empty one if you have nothing to report. If you do return JSON, these three arrays are shown in the popup:

{
  "saved":    [ { "email": "buyer@example.com", "order_id": 4147089582 } ],
  "queued":   [ "unmatched@example.com" ],
  "excluded": [ "you@yourshop.com" ]
}

Only the array lengths are used, to report "Pushed 13: 13 matched to an order". Anything else in the body is ignored, and a non-JSON body just means the count isn't broken down. A non-2xx status is reported as a failure and the CSV stays available in the popup.

Sent from the extension's service worker, so CORS is not enforced and your server does not need to send Access-Control-Allow-Origin headers — but it must be a host you approved above.

Data Handling

When enabled, collected orders will be cleared after successful export.
